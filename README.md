# MARIPOSA CRM — MVP 1

Первый тестовый каркас внутренней CRM MARIPOSA.

## Что уже есть
- Dashboard
- Навигация
- Каталог моделей товаров
- Модель → размеры → физические экземпляры
- Уникальный штрихкод каждого прокатного экземпляра
- Статусы: свободно / бронь / аренда / химчистка / ремонт
- Адаптивный интерфейс для телефона
- Тестовый экран входа
- Заготовки разделов: Заказы, Календарь, Склад, Клиенты, Финансы, WhatsApp, Настройки

## Запуск локально
```bash
npm install
npm run dev
```
Открыть http://localhost:3000

## Deploy на Vercel
1. Загрузить этот проект в репозиторий `Mariposa-crm`.
2. Импортировать репозиторий в Vercel.
3. Vercel должен распознать Next.js автоматически.
4. Нажать Deploy.

## Важно
Сейчас используются только демо-данные. Реальные персональные данные клиентов не загружать.
