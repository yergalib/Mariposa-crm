## Реализовано

- Обычные сообщения идут в conversational model: удалены готовые ответы и автоматический поиск для «любой цвет», относительных дат, просьбы подготовить черновик и подтвердить бронь. Убраны regex-подмены ответа после модели для сравнений цены. Кнопки выбора/удаления/периода остаются явными детерминированными действиями.
- `remember_request` атомарно сохраняет цитированные пожелания и календарное намерение. Модель выбирает инструмент; сервер вычисляет дату и проверяет доказательство. Неизвестная длительность сохраняется как `pendingRentalStart`, без выдуманного возврата; поиск наличия до полного периода блокируется.
- В instruction включены UTC-now, локальная дата, время и timezone выбранного разрешённого филиала. Противоречивое требование всегда уточнять относительные даты удалено.
- Ближайшая суббота включает сегодняшний день до закрытия окна выдачи; с 20:00 местного времени — следующая суббота, с явным флагом переноса. «Следующая суббота» и альтернативные/отрицательные даты не угадываются.
- Ответ «140» после вопроса о размере проходит существующую проверку evidence. Рост не превращается в размер. Исправления и отрицания сохраняют остальные поля. Отказ semantic reviewer откатывает календарные изменения.
- Пустой результат поиска показывается отдельным подтверждённым сервером фактом, не уничтожая естественный вопрос модели об альтернативе.
- Prices/availability остаются текущими server DTO; никаких write tools, автоматических броней, отправок, платежей, изменения прав или бизнес-логики аренды.

## Sol: локальная политика, ещё не опубликована

В owner-window основной ответ и validator используют `gpt-6.1-sol`, Responses, Standard/default, reasoning low. Права/окно/100 вызовов/$2 за день сохранены. Для остальных старых изолированных путей остаётся прежняя Luna policy. Старая owner price acknowledgement закрывает новый Sol provider; её нельзя сохранять при интеграции.

Официальные источники проверены чтением 21 октября:
- https://developers.openai.com/api/docs/models/gpt-6.1-sol
- https://developers.openai.com/api/docs/guides/function-calling

Sol поддерживает tools и structured outputs через Responses. `none`/`minimal` не поддерживаются. Standard за 1M токенов: вход $2, выход $10, cached input $0.10, cache writes $2.50. Доступность в конкретном API-аккаунте пока НЕ подтверждена: штатного read-only connector для списка моделей не найдено, ключи не извлекались. Astra отвергнута по цене и не включена.

Суммарный ledger прежний, строки не сбрасываются. Старые попытки консервативно переоцениваются по текущему более дорогому тарифу. Review cap 300 отличает reviewer от planning; неизвестные leases блокируют продолжение. Перед первым вызовом — read-only проверка бюджета на весь worst-case ход, затем каждый вызов по-прежнему резервируется транзакционно с advisory lock.

Резерв planning: $0.369512, review: $0.047300; минимальный ход (1+1) $0.416812, максимальный (3+1) $1.155836. Это консервативный резерв с 10% margin и максимальной ставкой cache-write, не фактический счёт. Если остаток меньше полного резерва, модель не вызывается. Старые Luna вызовы могут уже исчерпать доступный консервативный остаток после смены тарифа; обходить это нельзя.

В ответе authenticated owner предусмотрены только обезличенные usage/timing: модель, input/output/cache токены, расчёт стоимости по проверенному usage, latency. Reasoning входит в output и не оплачивается повторно в расчёте. `unknownUsageAttempts` включает неподтверждённые/блокированные попытки; это НЕ доказательство списания. Ошибка/неполный ответ провайдера не даёт нулевую стоимость и не освобождает неизвестный lease. Финальный счёт провайдера остаётся источником истины.

## Открытые ограничения

Живое качество Sol, 25s timeout и достаточность 300 output tokens для reasoning reviewer не проверены. Calendar resolver пока ограничен явно поддержанными русскими относительными словами, днями недели и точными датами; неопределённые/неподдержанные формулировки должны уточняться. Опечатка в самом слове даты не исправляется сервером автоматически. Память — ограниченное существующее состояние и последние сообщения, не новая долговременная память. Прежняя пользовательская приёмка и дефекты не объявлены закрытыми.
