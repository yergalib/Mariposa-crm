## Targeted evidence and boundaries

Only Next/@next and Sharp/@img dependency-family versions change. Lockfile integrity is compared with official registry metadata; no force downgrade or major Prisma/React update. The installed actual Windows native pipeline reports rsvg2.63.2, heif1.23.5 and vips8.18.7. Actual PNG/JPEG/WebP renditions preserve aspect ratio and source bytes, rotate EXIF correctly and strip metadata. Actual upload guards are exercised with mocked tenant product lookup and no DB/Storage access. SVG/HEIF/AVIF, MIME spoofing and oversized headers do not reach native rendition calls.

The dev test uses two own loopback servers, no secrets and an offline localhost-port1 database. Real isolated production-build HTTP/browser checks cover the protected document flow and a retained template server action; they never create owner sessions or real documents in Production. Typecheck and one webpack build validate the patch. Physical devices and Linux glibc exploit/runtime behavior are not tested here; registry Linux optional-package versions/integrity are checked, while observed native versions are Windows only.

The current Production remains exact a463784 with its approved migration and compatible rollback6a9efe. Read-only readiness checks confirm its published mapping, login form and protected-route redirects. No security candidate was uploaded, promoted or merged; the previously rejected service-alias action is not retried. Publishing a new candidate and updating its matching rollback need separate authorization.
