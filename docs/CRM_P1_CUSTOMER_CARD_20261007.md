# P1: связная карточка клиента — 2026-10-07

Продолжение локального P1 склада `0b8203200f11247bb2a82d71aee827cea0d188d5`; замороженный P0 — `5bbbec5afffbb99b3ab2de2a80d343a50991f0b1`. Работа выполнена в том же worktree, без новой модели клиента или финансового ledger.

## Изменения

- Первый экран: контакты с телефонными/email-ссылками, адреса, быстрые переходы к разделам и созданию аренды/продажи для активного клиента.
- Существующие формы контактов/адресов доступны в раскрывающемся блоке; заметки и их действия сохранены. Типы контактов и статус клиента отображаются по-русски.
- Последние заказы показывают тип, русский статус, филиал, период аренды либо дату продажи. Полная история поддерживает фильтры «Аренды / Покупки» с сохранением фильтра при переходе между страницами.
- Существующие платежи/возвраты, залоги и сальдо переиспользованы с их permission/branch guards. Ущерб и физические возвраты доступны через соответствующий заказ, без нового параллельного расчёта. История событий и документы — существующие сервисы.
- Новая аренда/продажа получает выбранного клиента без повторного поиска. Сервер разрешает предвыбор только активного клиента текущей организации и проверяет CUSTOMER_VIEW / ORDER_CREATE; SALE_CONFIRM сохраняется в маршруте продажи.
- При запрете ORDER_VIEW карточка не получает заказы/их количество из недоступных филиалов и не выводит раздел. Прямой маршрут списка заказов теперь проверяет CUSTOMER_VIEW и ORDER_VIEW; финансовая история дополнительно проверяет CUSTOMER_VIEW.
