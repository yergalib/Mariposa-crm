# Визуальный проход витрины

Основа `d9eaec6`; ориентир — предоставленный пользователем brief по официальному
каталогу Zara. Чужие логотипы, фотографии и тексты не использованы.

- Собственный текстовый wordmark MARIPOSA, белый фон, чёрный текст, Georgia
  для крупных заголовков, системный sans для интерфейса. Без загрузки шрифтов.
- Каталог: 4 колонки desktop, 3 на средней ширине, 2 mobile. Фото 2:3 — только
  честные заглушки «Фото скоро». Нет теней и скруглённых карточек.
- Обычный поиск остаётся основным, «Помочь с выбором» — вторичная опция.
  Фильтры филиал/название/размер/даты в раскрываемой панели; после успешного
  поиска панель закрывается. Условия результата остаются видимыми.
- Выбранный вариант: крупная область для будущей фотографии, компактная форма
  с филиалом, размером и датами; фокус переходит к форме. Пока только одна
  заглушка, не фиктивная галерея с выдуманными снимками.
- CTA «Оставить заявку на бронь», ожидание подтверждения сотрудником.
  Inquiry-only, без checkout/payment/резервирования. Серверный контракт, цены,
  доступность, права и все прежние блокеры не менялись.
- Категории, акции, отзывы, юридические обещания не добавлены.

Базовые typecheck/lint/build выполнены. Lint: 0 ошибок, 7 прежних предупреждений.
Локальный статический макет собран из настоящих React-компонентов и CSS,
с четырьмя явно синтетическими товарами, без цен и без БД. Просмотрены headless
Edge desktop 1440 px и эмулированный mobile 390 px; у mobile scrollWidth=390,
две колонки по 173 px, переполнения нет. Отдельный профиль браузера закрыт.
Первый обрезанный мобильный снимок заменён корректным viewport-снимком.

Это проверка внешнего вида каталога/фильтров, не браузерный E2E Next.js, не
проверка отправки, SQL, реальных товаров или галереи. Синтетика, HTML и PNG
находятся вне репозитория и не включены в сборку/коммит. Полный аудит отложен.
